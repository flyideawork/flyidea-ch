# flyidea.ch

Öffentliche Ankündigungsseite für flyidea: Desktop-Apps für Windows und
Linux. Kontakt: info@flyidea.ch. Keine Registrierung und kein Verkauf.

GitHub Pages veröffentlicht Änderungen an `main` automatisch. Es werden nur
HTML, CSS, ein lokaler Hell-/Dunkel-Schalter, Bilder und eine lokal bereitgestellte
Schrift veröffentlicht. Keine externen Skripte, Analysewerkzeuge, Cookies oder
App-Server. Nur die Farbauswahl wird lokal im Browser gespeichert.

Die Startseite und fünf statische Ratgeber behalten die Kernthemen der bisherigen
Website bei. Die Inhalte sind auf die kommende Desktop-Version angepasst.
Die ursprünglichen Ratgeber-Adressen bleiben erhalten. Jede Seite hat eigene
Metadaten, eine Canonical-Adresse und regionale hreflang-Verweise. Die Sitemap
enthält alle sechs Seiten; Inhalte sind ohne JavaScript lesbar. Die App-Vorschau
zeigt die helle Kursansicht der geöffneten Windows App. Anmeldedaten oder
API-Schlüssel sind auf der Aufnahme nicht sichtbar.

Die Schwesterseite liegt in [flyideawork/flyidea-de](https://github.com/flyideawork/flyidea-de).
Beide Seiten teilen Gestaltung und Inhalt; Canonical, Sitemap und CNAME passen
zur jeweiligen Domain. Änderungen an der Gestaltung sind in beide Repos zu übernehmen.

Die Schrift Figtree wird unter der SIL Open Font License bereitgestellt; siehe
`assets/Figtree-OFL.txt`.
